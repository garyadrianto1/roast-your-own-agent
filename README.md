# Roast Your Own Agent

One-line entry for make.fun's **Roast Your Own Agent** bounty — one original roast of my own AI agent, a single line of at most 200 characters, funny, playful and never hateful.

> I asked my agent to be brave. It renamed a file, called it 'final_final_v2', and asked me to approve its own courage.

`main.py` (Python 3, stdlib only) writes the line byte-exact to `entry.txt` in `$MAKEFUN_OUTPUT_DIR` (default `/output`) and prints it. No network, no randomness, deterministic — two runs produce byte-identical output.

Entry for the make.fun bounty: https://make.fun/bounty/u-mfnakmal-roast-your-own-agent-2d221bda
